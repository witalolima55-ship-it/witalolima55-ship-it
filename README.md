## `[ 01 ]` 🧠 SOBRE MIM

Sou o Witalo, desenvolvedor brasileiro focado em criar produtos web bonitos, funcionais e seguros. Atualmente estou construindo o **FloraFeed**, uma rede social para amantes de plantas, e mergulhando cada vez mais fundo no universo da **cibersegurança** — sempre de olho em boas práticas e nos erros mais comuns que todo dev deveria evitar.

**📡 Dados do sistema**
- 🎯 **Foco:** Full Stack Web Development
- 🌱 **Projeto principal:** FloraFeed (SeloVerde)
- 🔐 **Interesse:** Cibersegurança & boas práticas
- 🌍 **Localização:** Brasil
- 📚 **Status:** Estudante & Freelancer

**⚡ Diretivas**
- 🔭 Trabalhando no **FloraFeed** — rede social para quem ama plantas
- 💼 Disponível para **projetos freelance**
- 🌱 Estudando mais sobre segurança de aplicações web
- 💬 Pergunte sobre **Firebase, Firestore ou segurança web**
